## Before and after, the top 10

1. **No common frame** → every page header and shell sits in the site
   header's column (1152, content 1104).
2. **Colour meant three things** → generic actions (Sign in, Enter app, Try
   demo, links, focus) are ink; blue means only Call in. The landing's Create
   strip keeps its blue, now as the Call in key.
3. **Too many type styles** → one label style (sentence case, 12 bold,
   muted); 6 sizes, 2 weights site-wide.
4. **One pill for six jobs** → the feature tag is the only pill (hairline,
   dot, ink); statuses are a dot and a word; header page labels are plain
   text; counts and legends are plain muted text.
5. **Money had no single treatment** → ink, tabular, bold, 20px in rows.
6. **Bounties board** → amount leads, 4px meter, quiet row links, no washes.
7. **Dashboard** → status is the strongest line; the settings column rides
   along (sticky). The queue's place is unchanged (it already lifts when
   someone is waiting).
8. **Sparse pages** → empty states are column-wide panels; empty sections
   show nothing.
9. **Inverted emphasis** → Account: title-sized handle, flat panels, empty
   state demoted, one primary button. How it works: the camera-seat box is a
   card title. Notices are neutral (yellow means Bounty).
10. **Create campaign wall** → plain cards, ink selection, active rules
    stand out and off rules recede, one helper size.
